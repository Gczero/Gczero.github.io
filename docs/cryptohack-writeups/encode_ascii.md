# ASCII

你也许会对ASCII感到熟悉，如果你已经学习过了一些基础的程序设计或编程之类的课程，但对于初学者来说，一个新的名词总是会带来一定上的理解困难的，因此我们来简单解释一下ASCII。

## 全称与由来

对于Gczero来说，理解上的困难往往来源于缩写，当一个句子充斥着大量缩写只剩下虚词时，困惑程度将会指数级上升，直到成为灾难。

总而言之，ASCII的全称乃是**A**merican **S**tandard **C**ode for **I**nformation **I**nterchange，即美国信息互换标准代码。

我们都知道（或者说请接受这个设定），计算机只能处理二进制的数字，或者说数字，对于人类所使用的各类特殊符号，语言符号，是无法直接处理的，如果让每个人都自己把字符定义成数字，又会导致不统一的问题，因此需要一个通用的标准来解决这个问题，完成这项工作的便是ASCII，总之ASCII不是什么有高深知识和理论的东西，只要知道，就足够了。

ASCII码表的详细情况只需要直接搜索就行了，在此先不完整给出。
