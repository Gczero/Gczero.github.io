# Hex

还记得我们在ASCII篇章中说了什么吗？是的，ASCII解决的是字符转换为数字的问题，而如果你在上一章自己查找了完整的ASCII码表，应该可以发现除了对应的十进制数字，还有二进制、八进制、十六进制的对应，那么本章就将解决字符在转换为数字后，在不同进制之间的转换。

## 转换流程

从转换的完整流程来讲，对于一串十六进制数字符串，如6f122b3a，我们会拆解为6f，12，2b，3a四个十六进制数，然后每个十六进制数根据ascii码表查表转换为可见字母。

## Python的一点作弊（？）技巧

正如题目所述，python内置了一个可以将十六进制字符串（hex string）转换为字节（数据存储表示的最小单元，8位二进制数），文档是这么阐述的：


总而言之，fromhex()函数接受一个string类型的变量（诸如python中x='432419'的x）并将其切分为若干十六进制数

```e.g 6f122b3a->6f 12 2b 3a```

并将其以字节形式表示出来。直接打印出来一般会显示为```b'\x6f\x12\x2b\x3a'```

可以发现fromhex实际上就帮我们完成了完整流程中拆解的步骤，那为什么说这是一种作弊技巧呢（即我们实际不用显式地进行查表转换）

原因在于在打印```b'\x6f\x12\x2b\x3a'```这样的字符时，python解释器会先检查每一个字节，如果其可以根据ascii码表转换为可见字符，那就直接打印出转换后的字符，所以实际上会打印出```b'o\x12+:'```
