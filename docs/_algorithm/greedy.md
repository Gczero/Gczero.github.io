# Greedy Algorithm - 贪心算法

应该说贪心算法要比分治算法和动态规划算法要更容易理解，因为很多时候分治算法需要分析问题该如何分解，动态规划的问题本身容易第一眼看不出来好解法，而且现实生活中很少有人会直接去如此思考，而贪心算法之所以好理解很多，一是因为其思想符合人的直觉，只需要着眼于当下，寻求当前最好解，二是因为贪心算法在现实生活中的例子更加的丰富，并且在时刻使用中，最被频繁提及的例子便是凑钱数的问题。一般来讲，贪心算法解决的问题不是说很难找出某一个答案，而是对于找出最好的答案存在一定困难。

## 贪心算法的假设

既然贪心算法的思想基于每一步都选择当前的最优解，那么大多数人的第一反应是这一定是所有选择集合中最优的吗？

很遗憾，事实就是我们的想法是对的，贪心算法作出了一个非常大胆的假设，他希望每一个局部最优解最终一定会引向一个全局最优解，这明显不是任何情况都成立的。

到这里我们可能会说：**“这个贪心算法有什么用嘛，他的假设都是有问题的”**，但是要注意，我们从来没有说过贪心算法将要解出问题的最优解答，我们只需要这个算法能提供一个解决问题的路径，而贪心算法不仅能够解决问题，在一定概率上还能够进一步得出最好的路径，是不是相当出色）

我们先来看几个例子理解贪心算法是如何工作的。
